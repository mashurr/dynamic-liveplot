# Change Log

## [0.1.0]

- Plot CSV, TSV, JSON, JSON Lines, SQLite, Parquet and Excel files, charted automatically from their columns.
- Live updates for files that are still being written, following renames, truncation and replacement; pause and resume.
- Watch a folder to always plot its newest file, keeping the layout; compare with the previous run.
- 48 chart types with a gallery that suggests types for your columns, plus a custom ECharts type.
- Drag and drop columns onto plots, a side panel for every setting, and a collapsible column list.
- Limits with alerts, calculated columns, min/max/average marks, dual and log axes, smoothing and measuring cursors.
- Named and shared folder layouts (`.liveplot.json`, validated by a bundled schema), plot groups and column-name bindings.
- Overviews of files too big to keep whole, with every row of a zoomed range on demand.
- Export plots as PNG or SVG, copy images, save plotted rows as CSV, or save all plots as an image or an HTML report.
